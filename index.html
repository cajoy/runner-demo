Receipt

What one finished run leaves behind.

  • Ed25519 signature over the receipt bytes, carrying the signer id
  • A policy file on main says which keys are trusted, and what each may sign
  • Bound to a commit, a tree and a configuration digest
  • Records how one run ended, not current health or permission to run again
  • If the outcome was unknown, the receipt says so instead of guessing

Runner

One workflow, run anywhere: your laptop, cloud CI, an edge machine, or inside an enterprise network.

  • One 9 MB binary: CLI, MCP server, dashboard, receipt signing and the reuse check
  • Built for agentic flows, and fits any pipeline you already run
  • One local state behind CLI, MCP and dashboard
  • Agents only run workflows already in the repo, and Runner records who ran it, so it cannot be faked
  • Docker, Apple Container or the host, with more providers added as pinned plugins
  • Reuse only while source, toolchain, runtime and policy match
  • No hosted runner minutes
